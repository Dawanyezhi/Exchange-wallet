# 安全评审清单

## 密钥与地址

- 派生路径是否符合该链标准。
- 主网和测试网路径/前缀是否隔离。
- 公钥格式、地址编码和校验是否正确。
- 是否禁止打印 seed、私钥、chain code、助记词。
- 签名服务是否只返回签名，不暴露私钥。
- 签名审计是否包含请求方、地址、交易摘要、结果和拒绝原因。

## 签名前校验

- 链 ID、network ID、domain separator 或等价防重放字段是否正确。
- to、value、data/memo/tag/change 是否和业务单一致。
- Token 合约地址是否白名单校验。
- UTXO 输入是否全部属于系统并处于可花费状态。
- 找零地址是否属于系统。
- 手续费是否在上限内。
- 金额是否使用最小单位整数。

## 签后校验

- raw tx 反解析后是否和构建意图一致。
- 签名是否能本地验签。
- tx hash/txid 是否和落库记录一致。
- 输出、找零、memo/tag、合约地址、手续费是否再次核对。
- 广播前是否已锁定 Nonce 或 UTXO。

## 充值安全

- 是否等待足够确认数。
- 是否过滤失败交易。
- 是否校验 block hash 防重组重复入账。
- Token 是否校验事件签名、合约地址、log removed 标记。
- Memo/Tag 链是否校验 tag 归属。
- UTXO 链是否只把命中本系统地址的 output 作为充值。
- 是否有二次校验或多节点交叉校验。

## 提现安全

- 幂等键是否存在。
- 同一热钱包的 Nonce 或 UTXO 是否并发安全。
- 手续费异常是否拦截。
- RBF/加速是否保证用户目标输出不变。
- 失败、卡住、替换、重播是否有状态机。
- 大额提现是否有人工或风控审批。

## 归集安全

- 小额碎片是否考虑费用经济性。
- UTXO 链是否避免误花铭文、NFT 或未识别资产。
- 找零是否回到系统地址。
- 热冷转账是否有额度和频率限制。
- 归集失败是否不会释放已广播输入。

## 回滚与对账

- 是否保存足够区块头用于 parentHash 检测。
- 是否能找到共同祖先。
- 回滚是否一个事务完成。
- UTXO 链是否恢复被回滚交易花费的旧 UTXO。
- 深度重组是否暂停入账/出账并告警。
- 本地余额是否可由流水重建。
- 链上余额/UTXO sum 与本地账是否定时对账。

## 生产运维

- 节点是否双机或多机。
- RPC 是否只在内网暴露并启用鉴权。
- 节点落后、分叉、返回不一致是否告警。
- 外部数据平台是否只作为辅助。
- 是否明确 demo 与生产差距。
