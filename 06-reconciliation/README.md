# 06 - 对账系统

## 对账逻辑

每次对账（demo 中 10 秒间隔，生产中 2 秒）：
1. 从链下数据库获取统计余额
2. 从 RPC 查询链上余额
3. 检查高度差：本地高度和链上高度差 > 阈值 → 告警（同步落后）
4. 计算余额差：`diff = 链上余额 - 链下余额`
5. `|diff| > 阈值` → 余额偏差告警
6. 差值单调性追踪：`|新diff| > |旧diff|` → 差值在扩大（异常告警）

## 生产差距

- 对账周期本 demo 为 10 秒，生产中为 2 秒
- 生产中告警去重（45分钟内同内容只发一次）本 demo 简化为内存记录
- 生产中还有持续异常的历史记录
